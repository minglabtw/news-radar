# 心聞 · Heart News | 全自動 AI 新聞日報

> 每一天，都值得銘記。

心聞 · Heart News 是一個全自動化的 AI 智能新聞日報平台。每日自動聚合抓取多元中文新聞來源，經過 AI 深度分析、總結與評分，為您精煉出今日最值得關注的時事焦點。

👉 **即刻閱讀日報**：[https://minglabtw.github.io/news-radar/](https://minglabtw.github.io/news-radar/)

---

## 🌟 核心功能

- **🌅 每日定時更新**：每日早上 8:00 (台北時間) 自動發佈最新日報，精選當日重要資訊。
- **🎙️ 智能男聲播報**：內建高品質 AI 新聞主播男聲朗讀，完美適配智慧停頓起伏，為您用語音播報每日總編輯簡報。
- **⚡ 播放變速控制**：語音播放器支援 `1.0x`、`1.25x` 與 `1.5x` 三檔速度切換，隨心掌握收聽節奏。
- **📰 多領域分類卡片**：涵蓋科技綜合、每日綜合、財經市場、體育競技、生活探索五大領域，結構清晰。
- **🔮 今日焦點推薦**：首頁置頂 Spotlight 焦點推薦區，圖文並茂展示當日綜合評分最高的核心新聞。
- **🔖 熱門趨勢標籤**：自動統計當日高頻詞彙，精準呈現今日最熱門的時事趨勢。
- **🎨 高級視覺美學**：
  - 慢速莫蘭迪 Aura Glow 雙色霓虹呼吸背景。
  - 磨砂玻璃毛玻璃感 Masthead 與微光透明邊框。
  - 原生 CSS 幾何波紋雷達 Logo。
  - 播放時自動跳動的動態音頻聲波模擬。
  - 簡報底部的總編輯專屬手寫簽名卡。
- **📱 響應式與大字體自適應**：100% 支援手機/電腦排版，採用貼心的老花友善大字體，圖片加載失敗或無圖時自動隱藏並將文字自動撐滿，絕不破圖。
- **🔍 即時過濾與搜尋**：提供類別晶片（Chips）一鍵篩選及關鍵字即時搜尋，快速定位感興趣的文章。
- **📁 歷史過刊系統**：獨立的過刊網頁（Archive），方便隨時翻閱往期的新聞日報。

本倉庫為靜態網頁託管倉庫，僅包含以下前端靜態展示檔案：

- `archive.html`：歷史過刊牆。
- `logo.png`：日報品牌 Logo。
