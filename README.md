# 全自動化 n8n 新聞發布平台

> V5.3 贅字正則修復 | 最後更新: 2026-05-28

## 專案概述

本專案透過 n8n 自動化流程，抓取中文新聞來源，交由 MiniMax M2.7 推理模型進行分析、總結與評分，最終自動生成靜態網頁日報部署至 GitHub Pages，同時推送 Telegram 通知。

## 快速連結

| 服務 | 網址 |
|------|------|
| 新聞網站 | https://minglabtw.github.io/news-radar/ |
| 過刊牆 | https://minglabtw.github.io/news-radar/archive.html |
| n8n 管理介面 | https://n8n.sunder.net.tw |
| GitHub 倉庫 | https://github.com/minglabtw/news-radar |

## 核心功能

- ✅ 每日 8:00 AM (台北時間) 自動排程
- ✅ 16 個中文新聞來源、5 大領域 (科技、綜合、財經、運動、生活)
- ✅ MiniMax M2.7 推理模型、雙通道分流
- ✅ 靜態網頁部署至 GitHub Pages
- ✅ Telegram 推播通知
- ✅ LINE 推播通知 (待確認 Token 有效性)
- ✅ 過刊牆 (前端動態渲染)
- ✅ 網頁語音 API 女聲播報
- ✅ 多色 CSS 配色、深色模式
- ✅ 工具列晶片過濾、即時搜尋

## 一鍵部署

```bash
# 部署並觸發執行
node src/deploy_and_run.js
```
